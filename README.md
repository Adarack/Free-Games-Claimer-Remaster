# Free Games Claimer Remaster — Prebuilt Docker Image

Automated GHCR build of [P-Adamiec/Free-Games-Claimer-Remaster](https://github.com/P-Adamiec/Free-Games-Claimer-Remaster). All credit to the original author.

A GitHub Actions workflow checks upstream daily, builds when there are new commits, and pushes to:

```
ghcr.io/adarack/free-games-claimer-remaster:latest
ghcr.io/adarack/free-games-claimer-remaster:sha-<short>
ghcr.io/adarack/free-games-claimer-remaster:<YYYYMMDD>
```
